#  Notes API

Полноценное веб-приложение для управления заметками, написанное на **FastAPI** и **PostgreSQL** с собственной JWT-авторизацией и простым фронтендом на чистом JavaScript.

Каждый пользователь может зарегистрироваться, войти в систему и управлять **только своими** заметками.

## 🚀 Основные возможности (Features)
*   **Аутентификация и авторизация:** Регистрация и вход с использованием JWT (JSON Web Tokens).
*   **Безопасность:** Пароли хэшируются с помощью `bcrypt` (в базе не хранятся в открытом виде).
*   **Изоляция данных:** Пользователь видит и редактирует только свои заметки (защита на уровне SQL-запросов).
*   **Полный CRUD:** Создание, чтение (с пагинацией), обновление (частичное через PATCH) и удаление заметок.
*   **Фронтенд:** Готовый пользовательский интерфейс на HTML/CSS/JS, который общается с API.
*   **Документация:** Автоматическая интерактивная документация Swagger UI.

## 🛠 Технологический стек
*   **Backend:** Python 3.11+, FastAPI, Uvicorn
*   **База данных:** PostgreSQL, `psycopg` (драйвер)
*   **Безопасность:** `passlib[bcrypt]` (хэширование), `python-jose` (JWT)
*   **Валидация данных:** Pydantic
*   **Frontend:** HTML5, CSS3, Vanilla JavaScript (Fetch API)

Установка зависимостей

pip install -r requirements.txt

Настройка базы данных 

CREATE TABLE users (
    id SERIAL PRIMARY KEY,
    email VARCHAR(255) UNIQUE NOT NULL,
    password_hash VARCHAR(255) NOT NULL
);

CREATE TABLE notes (
    id SERIAL PRIMARY KEY,
    title VARCHAR(80) NOT NULL,
    content TEXT NOT NULL,
    user_id INTEGER REFERENCES users(id) ON DELETE CASCADE
);
